# Interpolate between two hex colors

Interpolate between two hex colors

## Usage

``` r
.interp_color(low, high, t)
```

## Arguments

- low:

  Hex color string for `t = 0`.

- high:

  Hex color string for `t = 1`.

- t:

  Numeric vector in `[0, 1]`.

## Value

Character vector of hex color strings.
